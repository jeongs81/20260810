## 목적

생성된 Wiki 파일이 원본 Raw 회의록과 정확하게 일치하는지, 또한 규칙을 제대로 따랐는지 LLM이 검증합니다.

**검증 대상**:
- Wiki 컨텐츠 vs Raw 회의록 일치도
- 임의 생성 콘텐츠 감지
- 누락된 중요 내용 확인
- 액션 상태 추적 검증

---

## 사용 시나리오

1. **새 Wiki 파일 생성 후 검증**
   ```
   /wiki-content-review wiki/2026-06-11-제품주간회의.md
   ```

2. **특정 Wiki 파일 재검증**
   ```
   /wiki-content-review wiki/2026-05-14-제품주간회의.md
   ```

3. **모든 Wiki 파일 일괄 검증**
   ```
   /wiki-content-review all
   ```

4. **상세 리뷰 모드**
   ```
   /wiki-content-review wiki/2026-06-11-제품주간회의.md --verbose
   ```

## 검증 단계

### 1단계: 파일 매핑
- [ ] Wiki 파일 읽음
- [ ] Frontmatter에서 `원본: raw/...` 추출
- [ ] 해당 Raw 파일 찾아서 읽음
- [ ] 파일 불일치 시 에러 처리

### 2단계: 기본 검증
- [ ] Raw와 Wiki의 회의일 일치
- [ ] Raw와 Wiki의 참석자 일치
- [ ] Wiki의 회의 요약이 Raw의 안건과 일치

### 3단계: 결정사항 검증
- [ ] Raw의 `### 결정` 섹션 모두 Wiki에 반영되었는가?
- [ ] Wiki의 결정이 Raw에 없는 내용은 아닌가?
- [ ] 각 결정의 근거(이유)가 Raw에 기반하는가?
- [ ] 결정의 이전 상태가 정확히 기록되었는가? (필요시)

### 4단계: 액션 검증
- [ ] Raw의 모든 액션 아이템이 Wiki에 반영?
- [ ] 액션의 담당자가 정확한가?
- [ ] 액션의 마감일이 정확한가?
- [ ] 액션의 상태([ ] / [x])가 정확한가?
- [ ] 의존성 표시가 Raw의 내용과 일치하는가?

### 5단계: 이전 액션 추적 검증
- [ ] Raw에 "이전 액션 상태 업데이트" 섹션이 있는가?
- [ ] Wiki의 "완료된 액션" 섹션이 Raw와 일치하는가?
- [ ] Wiki의 "미해결 액션" 섹션이 Raw와 일치하는가?
- [ ] 없는 액션이 "조용히 사라짐"은 아닌가?

### 6단계: 보류 항목 검증
- [ ] Raw의 보류 항목이 Wiki에 반영?
- [ ] 보류 항목의 해결 조건이 명확한가?
- [ ] 보류 상태가 이전 회의와 연속성이 있는가?

### 7단계: 의존성 검증
- [ ] Raw에 명시된 외부 의존성이 Wiki에 🔴로 표시?
- [ ] 내부 의존성이 🟢로 표시?
- [ ] 블로커가 ⚫로 표시?

### 8단계: 고위험 항목 검증
- [ ] 후속 액션의 선행조건이 🚨로 표시?
- [ ] 반복되는 지연/패턴이 분석되었는가?

## 검증 체크리스트

### 결정사항
- [ ] Raw의 모든 결정이 Wiki에 있는가?
- [ ] Wiki의 결정이 Raw에 근거하는가? (임의 생성 아닌가?)
- [ ] 근거(이유)가 Raw에서 충분히 추출되었는가?
- [ ] 이전 상태 변화가 정확히 기록되었는가?

### 액션 추적
- [ ] Raw의 모든 액션이 Wiki에 반영?
- [ ] 미완료([])와 완료([x])의 구분이 정확?
- [ ] 이전 회의의 액션 상태가 업데이트되었는가?
- [ ] 액션이 사라지지 않고 추적되고 있는가?

### 내용 정확성
- [ ] Wiki가 Raw의 내용을 정확히 반영?
- [ ] 임의로 추가된 내용은 없는가?
- [ ] Raw에 있는 중요 내용이 누락되지 않았는가?
- [ ] 수치(이탈률 42% 등)가 정확한가?

### 의존성 및 위험도
- [ ] 외부 블로커가 명확하게 표시?
- [ ] 반복되는 지연 패턴이 분석되었는가?
- [ ] 고위험 액션이 🚨로 표시?

## 가능한 문제점과 대응

### 문제: 액션이 조용히 사라짐
```
Raw (2026-05-14): [ ] 박준서 - 액션 A
Raw (2026-06-11): (언급 없음)
```
→ **경고**: 액션 A의 상태가 업데이트되지 않음

### 문제: 임의로 생성된 내용
```
Raw에 없는 내용이 Wiki에만 있음
예: "박준서는 A를 매우 중요하게 생각하고 있다" 
    (Raw에는 단순히 "A가 필요하다"고만 기록)
```
→ **오류**: 임의 생성 또는 과도한 해석

### 문제: 이전 상태 변화 미기록
```
Raw (2026-04-16): "5월 말 목표"
Raw (2026-05-14): "6월 중순으로 변경"
Wiki (2026-05-14): "6월 중순" (이전 상태 없음)
```
→ **경고**: 변화 과정이 기록되지 않음

### 문제: 의존성 표시 누락
```
Raw: "A사 응답을 기다리는 중"
Wiki: [ ] 액션 (의존성 표시 없음)
```
→ **경고**: 외부 블로커가 표시되지 않음

## 리뷰 결과 형식

### 통과 (✅ Pass)
```
✅ Wiki/2026-06-11-제품주간회의.md

검증 결과:
- 결정사항: 3개 모두 일치 ✅
- 액션: 4개 모두 추적됨 ✅
- 이전 액션: 완료/미해결 분리 정확 ✅
- 의존성: 외부 블로커 표시됨 ✅
- 고위험 표시: 정확 ✅

평가: 양호 (Minor warnings 0개)
```

### 경고 (⚠️ Warning)
```
⚠️  Wiki/2026-05-14-제품주간회의.md

발견된 문제:
1. [경고] 이전 액션 추적 부분
   - 강태우의 "계약 조건 확인" 액션이 Raw에 업데이트되지 않음
   - 2026-04-30 마감이었으나 상태 미명시
   
2. [경고] 보류 항목
   - 정산 주기가 보류 상태이지만 
     해결 조건이 명확하지 않음
```

### 실패 (❌ Fail)
```
❌ Wiki/2026-05-14-제품주간회의.md

발견된 오류:
1. [오류] 임의 생성된 내용
   - "A/B 테스트 결과 예상: 25% 감소"
   - Raw에는 "A/B 테스트 진행" 결정만 있음
   - 결과는 아직 나오지 않았음

2. [오류] 결정사항 누락
   - Raw에는 "일정 변경: 5월 말 → 6월 중순"
   - Wiki에는 이 결정이 없음

3. [경고] 외부 의존성 미표시
   - "A사 스펙 문서 확보" 액션이 A사에 의존
   - Wiki에서 의존성 표시 없음
```

  오류: 0개

## 주의사항

⚠️ **LLM의 판단이 최종이 아님**
- 사람이 Raw 회의록을 읽고 최종 검증
- LLM이 놓친 부분이 있을 수 있음

⚠️ **문맥과 뉘앙스**
- Raw의 간접적 표현을 Wiki에서 명시적으로 쓰는 것은 해석 (허용)
- 하지만 근거 없는 내용 추가는 오류

⚠️ **액션 추적의 중요성**
- 액션이 사라지는 것이 가장 큰 문제
- 이전 액션 상태 미기록은 반드시 경고
