## 목적

Raw 회의록 파일을 읽어서 CLAUDE.md의 규칙을 준수하는 Wiki 파일로 자동 변환 및 생성합니다.

**입력**: `raw/YYYY-MM-DD-[회의체명].md`  
**출력**: `wiki/YYYY-MM-DD-[회의체명].md`

---

## 사용 시나리오

1. **새 회의록이 추가되었을 때**
   ```
   /llm-wiki-ingest raw/2026-05-14-제품주간회의.md
   ```

2. **여러 회의록을 한 번에 처리할 때**
   ```
   /llm-wiki-ingest 2026-06-11
   ```
   (2026-06-11로 시작하는 모든 raw 파일)

3. **특정 Raw 파일의 Wiki를 재생성할 때**
   ```
   /llm-wiki-ingest raw/2026-04-16-제품주간회의.md --regenerate
   ```

## 실행 단계

### 1단계: Raw 파일 검증
- [ ] 파일명 규약 확인 (`YYYY-MM-DD-[회의체명].md`)
- [ ] 프론트매터 필수 필드 확인 (`회의일`, `참석`)
- [ ] 결정 섹션 존재 확인 (`### 결정`)
- [ ] 액션 섹션 존재 확인 (`## 액션 아이템`)
- [ ] 이전 액션 상태 업데이트 확인

### 2단계: 콘텐츠 추출
- [ ] 프론트매터 파싱
- [ ] 회의 요약 추출 (안건 기반)
- [ ] 결정사항 추출 및 구조화
- [ ] 액션 아이템 추출 및 분류
  - 미완료 액션 ([ ])
  - 완료된 액션 ([x])
  - 이전 액션 상태
- [ ] 보류(Pending) 항목 추출
- [ ] 의존성 및 위험도 식별

### 3단계: Wiki 구조 생성
- [ ] Wiki 프론트매터 작성
  - `원본: raw/...`
  - `회의일`, `회의체`, `참석`
  - `wiki_생성`, `마지막_업데이트`
  
- [ ] 회의 요약 섹션
  ```markdown
  ## 📋 회의 요약
  ```

- [ ] 결정 섹션
  ```markdown
  ## 🎯 결정 (Decision)
  ### 1. [항목]
  - **결정**: ...
  - **근거**: ...
  - **이전 상태**: ... (있으면)
  ```

- [ ] 액션 섹션
  ```markdown
  ## ✅ 액션 (Action)
  | # | 담당자 | 항목 | 마감 | 상태 | 의존성 |
  ```
  의존성: 🟢(내부) / 🔴(외부) / ⚫(블로커)  
  고위험: 🚨 표시

- [ ] 완료된 액션 섹션
  ```markdown
  ## ✔️ 완료된 액션 (이전 회의)
  ```

- [ ] 미해결 액션 섹션
  ```markdown
  ## ⏸️ 미해결 액션 (이전 회의)
  ```

- [ ] 보류 섹션
  ```markdown
  ## ⏸️ 보류 (Pending)
  ```

- [ ] 관련 항목 섹션
  ```markdown
  ## 🔗 관련 항목
  ```

### 4단계: 파일 생성
- [ ] Wiki 파일 생성 (`wiki/YYYY-MM-DD-...md`)
- [ ] 파일 생성 완료 메시지
- [ ] 원본 Raw 파일 경로 명시

---

## 검증 규칙 (CLAUDE.md 기반)

### Raw 검증 체크리스트
- [ ] 프론트매터: `회의일` (필수)
- [ ] 프론트매터: `참석` (필수)
- [ ] 파일명: `YYYY-MM-DD-[회의체명]` 형식
- [ ] 결정: `### 결정` 헤더 포함
- [ ] 액션: `## 액션 아이템` 포함
- [ ] 액션: `[ ]` 또는 `[x]` 체크박스 사용
- [ ] 이전 액션: 상태 업데이트 확인
- [ ] 의존성: 외부 요인 표시 확인

### Wiki 생성 규칙
- [ ] 원본 출처 명시: `원본: raw/...`
- [ ] 3계층 구조: 결정/액션/보류
- [ ] 액션 테이블: 의존성 컬럼 포함
- [ ] 고위험 액션: 🚨 표시
- [ ] 이전 액션: 완료/미해결 분리
- [ ] 결정: 근거 포함
- [ ] 다음 회의: 예상 안건 기록

## 오류 처리

### 필수 요소 누락 시
```
❌ [파일명] - 프론트매터의 '회의일' 필드가 없습니다
→ Raw 파일 수정 후 다시 실행하세요
```

### 파일명 규약 오류
```
❌ [파일명] - 파일명 규약을 따르지 않습니다
→ 형식: YYYY-MM-DD-[회의체명].md
```

### 결정/액션 섹션 부재
```
⚠️ [파일명] - '### 결정' 섹션을 찾을 수 없습니다
→ Raw 파일 수정 후 다시 실행하세요
```

## 주의사항

⚠️ **이전 액션 상태 업데이트는 필수**
- Raw에서 모든 이전 액션의 상태를 기록해야 함
- 없으면 Wiki에서 추적 불가능

⚠️ **의존성 표시의 중요성**
- 🔴: 우리 팀의 책임이 아님 (A사 응답 대기 등)
- 🟢: 우리 팀의 책임 (다른 액션 완료 필요)
- 리스크 관리를 위해 명확히 표시

⚠️ **다음 회의 예상 안건 기록**
- 현재 미해결 액션 기반
- 보류 항목 상태 기반
- 일정 연기 여부 기반
